# Лабораторный журнал — рабочая дизайн-система

Канон: DESIGN.md; машинные токены и reference-компоненты: .impeccable/design.json. Этот файл фиксирует реализацию, не меняя её.

## Визуальный язык

Плотный рабочий журнал: тёмная левая навигация, холодная бумажная область, белые прямоугольные таблицы с тонкими границами. Акцент на записи, фильтры и действия. Не использовать декоративные градиенты, крупные скругления, рекламные блоки и россыпь одинаковых карточек.

## Типографика и компоновка

Segoe UI, Arial, sans-serif; body 14px/1.5; h1 clamp(26px,3vw,38px), 1.15, weight 700, tracking -.035em; h2 20px, h3 16px. Таблица 13px, заголовки 10px uppercase. Кнопка минимум 36px, поля 38px, радиус элементов 2px, листов 0. Focus-visible 3px.

Rail 254px, sticky, высотой viewport; topbar 76px; main с отступами 30px 34px 50px. Межколоночный gap 24px. До 1100px обзор/детали становятся одноколоночными. До 760px rail открывается кнопкой меню, topbar 66px, основной отступ 16px, формы одноколоночные. Таблицы скроллятся внутри .table-scroll, а не вся страница. При ширине от 1600px main ограничен 1600px. Reduced motion отключает анимации.

В reference DESIGN.md указаны 1050px и горизонтальная мобильная навигация. Фактический CSS использует 1100px и открываемый rail. Не переносить reference-размеры механически.

## Компоненты

| Класс | Назначение |
|---|---|
| .rail, .nav, aria-current=page | Группы разделов/активный маршрут |
| .page-heading, .actions | Заголовок, пояснение, действия |
| .sheet, .sheet-head, .sheet-body | Реестр/сведения/форма |
| .filters, .table-scroll | Поиск, фильтры и таблица |
| .btn.primary, .btn, .btn.danger | Основное/вторичное/опасное действие |
| .field, .form, .form-error | Подписанные поля и ошибки |
| .status, .notice | Состояния и предупреждения |
| dialog, .toast | Временная форма и подтверждение |
| .empty, .loading | Пустое состояние и загрузка |
| .details, .prose, .photo-grid | Карточки, многострочный текст, фото |

Helpers в frontend/js/dom.js: el/field/form/modal/button/table. Пользовательские строки вставлять DOM-методами как текст, не через HTML-конкатенацию. Label, клавиатурная навигация, focus-visible и состояния ошибок обязательны. Новый экран проверять на guest/staff/admin, пустых данных, длинном русском тексте и ширине 390px. Ассистенты пока явно обозначены как будущие возможности.
